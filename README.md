# Theo Nogueira - Photography Portfolio

## Project Overview
A minimalist photography portfolio website for Theo Nogueira, inspired by clean, modern design aesthetics similar to Anna Mendes' portfolio. The website features a black, white, and gray color scheme with clean sans-serif typography and an organic portfolio layout.

## Features Implemented

### ✅ Completed Features

1. **Minimalist Design**
   - Black, white, and gray color palette
   - Clean sans-serif typography (Inter font family)
   - Minimal, distraction-free layout
   - Professional and modern aesthetic

2. **Navigation Menu**
   - Fixed header with blur effect
   - Menu tabs: Home, Film, Stills, About, Contact
   - Smooth scrolling between sections
   - Active link highlighting
   - Mobile hamburger menu

3. **Organic Portfolio Layout**
   - Asymmetric grid system
   - Varying aspect ratios for visual interest
   - Hover effects with subtle scaling
   - Lightbox modal for image viewing
   - Sample content with photography icons

4. **Portfolio Sections**
   - **Film** - Motion picture work and cinematography
   - **Stills** - Photography and still imagery
   - Separate galleries for different media types

5. **About Section**
   - Clean, centered layout
   - Professional bio text
   - Circular profile placeholder
   - Minimal design approach

6. **Contact Section**
   - Simple contact form
   - Contact information display
   - Social media links
   - Clean, functional design

7. **Responsive Design**
   - Mobile-first approach
   - Tablet and desktop optimizations
   - Touch-friendly interactions
   - Collapsible mobile navigation

8. **Interactive Features**
   - Smooth scrolling navigation
   - Portfolio filtering by category
   - Lightbox image viewer
   - Form validation and submission
   - Scroll animations and effects

## Technical Details

### Color Scheme
- Primary: #000000 (Black)
- Secondary: #ffffff (White)
- Grays: #f5f5f5, #e5e5e5, #d4d4d4, #a3a3a3, #737373, #525252, #404040, #262626, #171717

### Typography
- Primary: Inter (Google Fonts)
- Weights: 300, 400, 500, 600
- Letter-spacing optimized for readability

### Technologies Used
- HTML5 semantic structure
- CSS3 with CSS Grid and Flexbox
- Vanilla JavaScript (ES6+)
- Font Awesome icons
- Google Fonts

## File Structure
```
index.html          # Main HTML structure
css/style.css     # Complete styling
js/main.js        # Interactive functionality
```

## Usage

### Navigation
- Click navigation links to smoothly scroll to sections
- Mobile menu accessible via hamburger icon
- Active section highlighting during scroll

### Portfolio
- Browse Film and Stills sections separately
- Click on portfolio items to view in lightbox
- Navigate lightbox with keyboard (ESC to close)

### Contact Form
- Fill in name, email, and message fields
- Email validation included
- Form submission confirmation

## Entry Points

### Main URLs:
- `/` - Homepage with hero section
- `#film` - Direct link to film portfolio
- `#stills` - Direct link to stills portfolio  
- `#about` - Direct link to about section
- `#contact` - Direct link to contact section

### Form Endpoints:
- Contact form submission (client-side simulation)
